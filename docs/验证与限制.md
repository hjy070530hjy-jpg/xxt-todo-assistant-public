# 验证与限制

当前发行版为v0.1.4预览版。此文件只包含软件验证信息，不发布任何账户的课程数量、作业数量、消息内容、会话或真实账户截图。

## 已完成

- Windows 11 x64 / Python 3.14.7 / PySide6 6.12.0 / PyInstaller 6.22.3实际构建并启动无控制台程序。
- 480×270横向窗口、左侧课程/作业/消息导航、两主题、独立设置页及100%/150%显示缩放检查。
- 网页登录组件加载、内存浏览器profile、Windows当前用户DPAPI加解密往返检查。
- 经账户持有人授权，在本机做过课程列表、部分课程进度、作业详情/日期字段、通知分页只读抽查。不代表覆盖所有学校和账户。
- 42项自动化回归测试通过：状态判断、日期精度、通知状态分离、分页与重复页、同步失败保留缓存、DPAPI和账户隔离、提醒去重与截止变化、详情按钮、课程字段简化、右键删除/设置内撤销、撤销入口与账户隔离、删除与撤销保留滚动位置、底部位置收缩、快速切换页面、逾期作业隐藏及可靠日期边界、截止时间延长后重新显示、删除后不提醒、设置主题预览/保存、失败条目隐藏及查询恢复后重新显示。
- 百宝箱图标与悬停介绍、双击内存清理、防止重复执行、净变化计算与失败状态；Windows 11 x64 原生清理接口已实际运行成功。普通账户下的完整 UAC 交互和其他 Windows 版本未独立实机验收。
- 仅读取数据，没有实现刷课、答题、提交作业、通知确认或平台已读写入接口。

仓库assets/下的图片均由示例数据生成，顶部明确标注示例；不包含真实账户截图。

## 已知限制

1. 使用社区研究的网页内部接口，不是官方公开API，平台更新可能造成解析失效。单个账户抽查不代表跨学校兼容性保证。
2. 通知的要求确认、已确认及确认截止字段无法可靠取得；不能把未读当成未确认，也不能可靠提醒“新待确认通知”。
3. 部分作业只有相对倒计时、无年份日期或无截止字段。保留可获取原文，不推算年份、23:59或精确截止。缺失完整日期的项目不生成绝对日期提醒。
4. 课程结束时间不是任务点截止；部分课程没有可靠汇总。界面仅显示课程结束和完成状态，无法可靠判断时为未知。
5. 失败/不支持条目按当前界面规则隐藏，后台缓存保留并继续重试。没有可显示内容不等于没有待办或已经完成。
6. 课程响应是否覆盖全部课程仍需要平台页面抽查；作业和通知最多100页，触及上限报不完整。
7. 系统托盘通知受Windows通知设置、勿扰模式、休眠和退出影响，不承诺关闭或休眠期间实时提醒。自启动由用户在设置中开启。
8. 透明模式是半透明回退实现，非系统原生毛玻璃；多显示器热插拔、第二台干净电脑和Windows 10尚未完成实机验收。
9. 程序为未签名的单文件 EXE；运行时会自动释放必要组件。网页登录组件使包体积较大。

## 用户抽查

登录后对照学习通原页面检查课程列表、未交与待批阅作业、截止年份与时刻、课程完成状态和未读通知。反馈问题时只提供脱敏错误信息和结构，不提交密码、Cookie、二维码、验证码或数据库。
