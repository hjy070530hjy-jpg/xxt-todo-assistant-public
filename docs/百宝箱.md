# 百宝箱

## 内存清理

双击绿色内存芯片图标进行清理，单击不会执行。鼠标悬停显示介绍；完成后显示可用内存净增加量、当前可用内存和总内存。系统要求管理员授权时由用户手动允许，取消则不执行。后台清理期间不能重复触发，不关闭其他应用。实现研究及限制见[内存清理研究](内存清理研究.md)。

## Geek Uninstaller

GitHub 的 Windows 单文件 EXE 已内置 Geek Uninstaller 1.6.0.200。下载一个 EXE 后即可使用，无需配套目录、额外下载或选择路径。启动时自动释放运行组件，Geek 通过经过哈希校验的缓存工作副本独立打开。

在“设置 → 百宝箱”中点击 Geek 图标，即可在独立窗口使用 Geek Uninstaller。鼠标停留在图标上会出现介绍浮层，配色、圆角和透明背景与当前主题保持一致；移开鼠标后收起。

单文件 EXE 内部包含用户提供的 Geek Uninstaller 1.6.0.200；原始数字签名有效，复制与打包时保持文件不变。若文件被移走，点击图标会提示重新指定 geek.exe。用户选择的路径仅保存在本机设置中。图标来自该程序的图标资源，相关标识归原权利人所有。

关闭 Geek 不会退出学习通待办助手。卸载软件等操作由用户在 Geek 窗口中自行完成，助手仅负责启动工具。

源码不包含第三方可执行文件。自行构建时，可将自己取得的 geek.exe 放到项目的 extras/geek/geek.exe，再运行 build.bat；构建脚本会将它封装进单个 EXE。缺少此文件时发行构建会明确报错，避免生成不完整的单文件程序。

Geek Uninstaller 是独立的第三方软件，不属于本项目的 MIT 许可范围。Windows 单文件发行版包含用户提供的原始可执行文件，文件内容与数字签名均保持不变；第三方权利声明见 THIRD_PARTY_NOTICES.md。

## 本机离线设置

已通过 Windows 防火墙为用户提供的 Geek、源码目录副本、百宝箱运行副本和实际解包的 geek64.exe 设置出站阻止规则，三个网络配置文件均适用。规则组名为 `XXTAssistant Geek Offline`，不改变其他应用的网络规则。

这是当前电脑上的程序路径规则，未修改 Geek 可执行文件，其签名保持有效。复制到其他电脑、改名或更换解包路径后，需要重新设置规则。阻断更新联网不等于删除程序内的更新界面；手动点击更新时仍可能出现连接失败提示。
