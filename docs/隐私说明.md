# 隐私与本地数据

- 应用直接从本机访问学习通相关HTTPS页面，没有本项目运营的服务器，也不依赖大模型API进行同步。
- 用户在学习通登录页面输入密码或扫码；应用不保存密码。内嵌网页登录使用内存profile，不持久化浏览器Cookie数据库。
- 会话、SQLite缓存、设置、提醒去重和本地删除标记以当前Windows用户DPAPI加密，默认位于 `%LOCALAPPDATA%/XXTTodoAssistant/data.sqlite3`。
- 退出账户删除当前会话并停止其提醒。缓存按账户隔离；清除本地数据删除所有账户会话与缓存，保留界面设置。
- DPAPI与Windows用户绑定。更换用户或重装系统后可能无法解密，需要重新登录。
- 发布源码和便携程序包不包含任何本机账户会话、数据库、真实课程/作业/消息内容、调试探测脚本或真实账户截图。
- GitHub凭据由GitHub连接方式管理，不属于本应用的学习通账户数据。不要把任何令牌写进源码、配置或Issue。
